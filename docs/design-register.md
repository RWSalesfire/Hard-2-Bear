## Rules

- **Never reuse:** the same palette (main colours within a close shade), the same type pairing, or the same hero layout and idea.
- **Shared on purpose, never visible:** booking integrations, schema, the care-plan update setup, unstyled building blocks.
- **Same trade, same town:** be extra careful. Two pubs on one high street must look nothing alike.
